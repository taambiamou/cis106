# Notes 1 

## What is Markdown?
Markdown is a lightweight markup language used to format text in a simple, readable way. It’s widely used in documentation, blogs, and note-taking because it allows to add headings, lists, links, images, and emphasis (bold/italic) using plain text symbols like #, *, or []().



## What is Git?
Git is a version control system that allows developers to track changes in files, save versions of their work, and collaborate without overwriting each other’s progress. It helps manage branches, merges, and rollbacks, making teamwork on coding projects much easier.



## What is GitHub?
GitHub is an online platform built on top of Git that hosts repositories and provides collaboration tools. Developers use it to share code, review changes, open issues, and work together on projects, making it both a code-sharing site and a collaboration hub.



## What is Slack?
Slack is a team communication platform that allows real-time messaging organized into channels and direct messages. It also supports file sharing and integrates with tools like GitHub and Google Drive, helping teams stay connected and work together efficiently.
